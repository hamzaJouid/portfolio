Voici un guide simple et clair pour accomplir ces 3 étapes : modifier vos données, mettre votre portfolio en ligne (URL/lien), et générer votre QR Code.Étape 1 : Modifier vos informations personnellesToutes les informations visibles du portfolio sont regroupées dans le fichier index.html.  Ouvrez le fichier index.html dans un éditeur de texte (VS Code, Notepad++, etc.).Nom & Titre (Section Accueil) :Recherchez la balise <h1 class="glitch" et modifiez le texte HAMZA par votre prénom ou pseudo :  HTML<h1 class="glitch" data-text="VOTRE_NOM">VOTRE_NOM</h1>
Modifiez votre sous-titre ou métier au-dessus (<p class="pre-title">).  Vos Projets (Section Projets) :Parcourez le bloc <div class="holo-grid">. Vous y trouverez des blocs <article class="holo-card">.  Remplacez les titres (<h3>), descriptions (<p>) et tags (<span class="card-tag">) par vos projets réels.  Votre Bio & Compétences (Section Profil) :Modifiez le paragraphe <p class="bio"> avec votre texte explicatif.  Ajustez les compétences (<div class="skill">) ainsi que les pourcentages affichés dans l'attribut data-level (ex: data-level="90").  Vos Liens & E-mail (Section Contact) :Modifiez l'adresse e-mail dans l'élément <a href="mailto:votre@email.com" class="contact-mail">.  Dans <div class="socials">, modifiez les attributs href="#" pour y ajouter les URL vers vos réseaux (ex: href="[https://linkedin.com/in/votre-nom](https://linkedin.com/in/votre-nom)").  Étape 2 : Publier le portfolio en ligne (Rendre accessible via un lien web)Pour que n'importe qui puisse y accéder sur Internet, vous devez héberger vos fichiers (index.html, style.css, script.js) sur un serveur. La méthode la plus simple et 100% gratuite est GitHub Pages ou Vercel / Netlify.  Option A : Vercel / Netlify (La méthode sans ligne de commande)Créez un compte gratuit sur Netlify.com ou Vercel.com.Glissez-déposez le dossier complet de votre projet (contenant vos 3 fichiers) directement sur l'interface du site.En quelques secondes, le site vous attribuera un lien public gratuit (du type [https://mon-portfolio.netlify.app](https://mon-portfolio.netlify.app)).Option B : GitHub PagesCréez un compte sur GitHub.com.Créez un nouveau dépôt public (Repository).Téléversez-y vos 3 fichiers (index.html, style.css, script.js).  Allez dans Settings > Pages > sélectionnez la branche main puis cliquez sur Save.Votre site sera accessible sous quelques minutes à l'adresse https://votre-pseudo.github.io/nom-du-repo.Étape 3 : Créer un QR Code lié à votre portfolioUne fois votre lien web obtenu à l'étape 2 :Rendez-vous sur un générateur de QR Code gratuit (par exemple qr-code-generator.com ou me-qr.com).Collez l'URL de votre portfolio (ex: [https://mon-portfolio.netlify.app](https://mon-portfolio.netlify.app)).Téléchargez l'image du QR Code (au format PNG ou SVG).Vous pouvez désormais imprimer ce QR Code sur vos cartes de visite, votre CV ou vos présentations. Lorsqu'un utilisateur le scannera avec son smartphone, votre portfolio futuriste s'affichera directement !
